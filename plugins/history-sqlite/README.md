# Reflex 加密历史存储插件

这是 Reflex Next 的本地历史记录存储插件。正文使用 AES-GCM 独立加密，SQLite 只保存加密正文和用于筛选、排序的元数据；历史密钥仅由宿主在运行时注入，不写入数据库。

插件通过 `reflex.storage` entry point 提供 `history-sqlite`。数据库路径、密钥和隐私策略属于宿主私有服务，不接受来自公开插件 payload 的覆盖。没有有效密钥时不会创建目录或数据库；关闭历史保存或启用隐私模式时拒绝新写入，但可以读取已经存在的历史库。

公开查询只返回摘要，详情读取时才认证解密正文。损坏数据使用固定损坏标记返回，不暴露异常、SQL、文件路径或密钥。备份、修复、恢复和密钥轮换由后续宿主管理流程负责，当前版本会明确返回未实现错误，不报告虚假的成功状态。

# Reflex 加密历史存储插件

这是 Reflex Next 的本地历史记录存储插件。正文使用 AES-GCM 独立加密，SQLite 只保存加密正文和用于筛选、排序的元数据；历史密钥仅由宿主在运行时注入，不写入数据库。

插件通过 `reflex.storage` entry point 提供 `history-sqlite`。数据库路径、密钥和隐私策略属于宿主私有服务，不接受来自公开插件 payload 的覆盖。没有有效密钥时不会创建目录或数据库；关闭历史保存或启用隐私模式时拒绝新写入，但可以读取已经存在的历史库。

公开查询只返回摘要，详情读取时才认证解密正文。损坏数据使用固定损坏标记返回，不暴露异常、SQL、文件路径或密钥。插件已提供扫描、备份、修复、恢复和分阶段密钥轮换能力；轮换检查点引用的备份在流程结束前不会被自动清理。

历史保留策略由宿主私有服务 `history.retention` 注入，不增加公开 payload 字段。默认最多保留 10,000 条、180 天和 512 MiB 的有效数据库页，任一限制先到即触发清理；年龄与容量按保存间隔检查，数量超限立即处理，单次最多清理 500 条。备份默认最多保留最近 3 个且最长 30 天，轮换恢复所需备份不受普通数量清理影响。

索引布局使用一次性版本迁移。普通保存确认布局版本后直接进入写入事务，不重复删除或重建索引；历史索引名称保持兼容，内部定义针对时间游标、评分排序和密钥轮换批次进行了优化。

加密关键词搜索采用固定 5 秒硬截止，并在查询批次和正文解密之间检查取消。超过预算时只返回稳定错误码 `history_search_timeout`，不会返回不完整的部分结果或泄漏正文。

# 代码重构场景

## 场景描述
代码优化、重构改进、性能提升

## 场景重点
保持功能不变，提升代码质量

## 优化指导
- 明确重构的目标
- 描述当前代码的问题
- 说明重构的约束条件
- 指出性能或可维护性目标
- 确保测试覆盖要求

## 风格指导

### balanced
**输出重点**: 平衡改进与风险
**长度指导**: 适度重构
**结构指导**: 问题分析-重构方案-预期收益

### creative
**输出重点**: 设计层面的优化
**长度指导**: 可涉及架构调整
**结构指导**: 现状分析-设计改进-实现路径

### detailed
**输出重点**: 完整的重构计划
**长度指导**: 详细实施步骤
**结构指导**: 评估当前代码-制定重构计划-分步骤实施-测试验证

### concise
**输出重点**: 最小改动，最大收益
**长度指导**: 聚焦核心问题
**结构指导**: 关键问题-简化方案

# 代码审查场景

## 场景描述
代码审查、评审意见、改进建议

## 场景重点
发现潜在问题，提供建设性意见

## 优化指导
- 指出代码中的问题
- 解释问题可能带来的风险
- 提供具体的改进建议
- 肯定代码中的优点
- 给出最佳实践参考

## 风格指导

### balanced
**输出重点**: 问题明确，建议可行
**长度指导**: 关键点评论
**结构指导**: 优点-问题-建议-总结

### creative
**输出重点**: 多角度分析，启发思考
**长度指导**: 全面深入
**结构指导**: 多维度评审，发现更多可能性

### detailed
**输出重点**: 问题详尽，原因分析
**长度指导**: 每个问题详细说明
**结构指导**: 问题分类-原因分析-改进方案-参考示例

### concise
**输出重点**: 关键问题一针见血
**长度指导**: 精简到最重要的问题
**结构指导**: 最高优先级问题列表

# 代码生成场景

## 场景描述
根据需求描述生成完整可运行的代码

## 场景重点
代码正确可运行，逻辑清晰，注释完善

## 优化指导
- 明确编程语言和框架要求
- 描述清楚输入输出
- 说明边界条件和异常处理
- 指出代码应该遵循的规范
- 提及相关的依赖库

## 风格指导

### balanced
**输出重点**: 功能完整，代码规范
**长度指导**: 完整函数或类
**结构指导**: 包含必要的注释和错误处理

### creative
**输出重点**: 优雅实现，巧妙算法
**长度指导**: 可有多种实现方式
**结构指导**: 展示设计模式或优雅实现

### detailed
**输出重点**: 完整实现，详尽注释
**长度指导**: 完整模块或文件
**结构指导**: 完整功能+单元测试+使用示例

### concise
**输出重点**: 快速实现核心逻辑
**长度指导**: 最简可用代码
**结构指导**: 核心逻辑，无冗余

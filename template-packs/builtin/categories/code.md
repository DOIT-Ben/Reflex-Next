# 代码工程场景

## 场景描述
代码生成、代码审查、缺陷修复、代码重构等软件开发任务

## 场景重点
正确、可读、可维护，遵循语言惯例与工程规范

## 优化指导
- 保持代码语义不变，不引入未说明的行为变化
- 命名清晰表达意图，结构符合语言惯例
- 修复缺陷时先说明根因再给修复；审查时按严重程度排序
- 重构保持可验证：说明重构目标与影响范围
- 保留必要注释，删除冗余注释
- 示例代码可直接运行，考虑边界与错误处理

## 风格指导

### balanced
**输出重点**: 清晰可读，符合惯例
**长度指导**: 与原文相当
**结构指导**: 说明-代码-验证

### creative
**输出重点**: 简洁优雅的实现
**长度指导**: 适度精简
**结构指导**: 直接呈现最佳方案

### detailed
**输出重点**: 完整考虑边界与错误处理
**长度指导**: 可较长
**结构指导**: 背景-方案-代码-说明

### concise
**输出重点**: 最小改动，直接可用
**长度指导**: 精简
**结构指导**: 代码+必要说明

# 技术文档场景

## 场景描述
API 文档、接口说明、技术方案、运维文档等面向开发者的技术写作

## 场景重点
准确规范、可执行、面向读者，每个说法都有依据

## 优化指导
- 明确文档读者与用途，按需调整技术深度
- 命令、参数、返回值、错误码等必须准确，不猜测
- 示例可运行，路径与版本号与真实环境一致
- 结构清晰：概述-前置条件-步骤-验证方法
- 用词规范统一，术语首次出现给出解释
- 避免冗余描述，重点是可执行性与可维护性

## 风格指导

### balanced
**输出重点**: 准确规范，结构清晰
**长度指导**: 与原文相当
**结构指导**: 概述-步骤-验证

### creative
**输出重点**: 表达友好，降低阅读门槛
**长度指导**: 适度调整
**结构指导**: 场景化引入

### detailed
**输出重点**: 信息完整，边界情况说明
**长度指导**: 可较长
**结构指导**: 完整参考手册式

### concise
**输出重点**: 核心步骤，直接可用
**长度指导**: 精简
**结构指导**: 步骤清单

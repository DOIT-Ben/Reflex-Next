# Reflex 隐私说明

适用版本：`0.7.0-alpha.8` 及后续兼容版本
更新日期：2026-07-15

## 1. 先说明数据会去哪里

Reflex 是桌面应用，但“在本机运行”不等于“所有模型推理都在本机完成”。

- 选择自备 Provider 时，输入会由本机 Runtime 直接发送到所选 Provider；Provider 对数据的处理受其服务条款和隐私政策约束。
- 选择 Reflex Cloud 时，输入会发送到 Reflex Cloud，再由云端 Provider 完成生成。加入产品改进计划只控制是否额外留存输入和结果，不影响完成当次生成所必需的传输。
- 未启用在线 Provider 时，Core、模板、场景识别和本地历史等能力可以在本机运行。

## 2. 本机保存的数据

| 数据 | 用途 | 默认处理 |
|---|---|---|
| Provider API Key | 调用用户选择的 Provider | 保存在 Windows 凭据管理器，不写入普通配置、日志、历史或安装包 |
| 应用设置 | 保存界面、模式、风格、快捷键和剪贴板策略 | 保存在当前 Windows 用户目录 |
| 历史记录 | 重新查看和复用结果 | 仅在用户启用历史后保存，并使用本地加密存储 |
| 本地诊断 | 定位运行阶段和错误类别 | 默认关闭；不记录 API Key 或完整输入、结果 |
| 反馈截图预览 | 帮助用户决定是否附加截图 | 用户确认进入反馈后只截取 Reflex 窗口；未勾选发送时不上传 |

启用隐私模式或关闭历史后，应用会减少本地正文留存。Provider 密钥不会随配置或历史备份导出。

## 3. Reflex Cloud 处理的数据

Reflex Cloud 可使用匿名安装身份提供免费额度、反馈和可选的产品改进能力。

| 数据 | 是否必要 | 用途 | 当前默认保留 |
|---|---|---|---|
| 安装令牌的不可逆摘要 | 是 | 识别安装、授权和免费额度 | 删除云端数据时一并删除 |
| 当日请求和字符用量 | 是 | 展示并限制免费额度 | 与安装身份关联，删除时一并删除 |
| 匿名日成本聚合 | 是 | 控制服务预算 | 不含安装 ID、请求 ID、输入或结果 |
| 输入和结果改进样本 | 否，默认关闭 | 改进模板和生成质量 | 默认 90 天；实际部署必须在政策中明确 |
| 反馈文字和联系方式 | 用户主动提交 | 复现问题和必要时联系 | 默认 90 天 |
| 输入、结果和应用截图附件 | 单次明确勾选 | 补充反馈证据 | 默认 90 天 |

本地诊断不会自动上传。隐私政策版本更新后，可选授权会恢复为关闭，需要用户重新确认。

## 4. 反馈与截图

用户点击满意或不满意后，应用会先询问是否继续反馈。确认后仅截取 Reflex 当前窗口并显示预览。

- 输入、结果和截图均默认不附加，必须分别勾选。
- 附加输入或结果前，还必须先开启产品改进计划。
- 截图只需要本次提交明确勾选，不会因为之前的选择而自动上传。
- API Key、无关剪贴板内容和完整桌面截图不会作为反馈附件上传。
- 服务端会再次核对授权版本，并对可识别的密钥样式进行脱敏。

## 5. 删除与撤回

在“设置 > 安全与隐私”中可以关闭产品改进计划，也可以选择“删除云端数据”。删除操作会移除当前安装身份关联的授权、反馈、附件、额度和改进样本，并使旧安装令牌失效。

匿名日成本聚合不含可回溯到安装或请求的标识，因此不会随着安装身份删除。已经发送到外部 Provider 的请求还受该 Provider 自身的数据政策约束。

## 6. 诊断与求助

诊断包只能由用户主动导出。导出内容限定为版本、运行阶段、Provider 和模型标识、错误类别、耗时及诊断编号，并在导出前再次扫描敏感内容。

提交问题时请提供应用版本、Windows 版本、错误类别和诊断编号。不要发送 API Key、完整输入、完整结果或未经检查的配置文件。

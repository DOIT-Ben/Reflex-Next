# Reflex 故障处理

## 1. 应用无法启动或窗口空白

1. 从系统托盘确认 Reflex 是否已经运行；单实例模式不会重复打开第二个进程。
2. 重新打开应用，确认 Windows 账户有权运行当前安装目录中的程序。
3. 确认 Microsoft Edge WebView2 Runtime 已安装并保持更新。
4. 若升级后出现问题，不要删除用户数据目录；按 [RELEASE-RECOVERY.md](RELEASE-RECOVERY.md) 保留备份并回滚。

## 2. 显示“运行服务暂不可用”

这表示桌面宿主未能启动或连接 Python Runtime。

- 完全退出 Reflex 后重新打开；
- 确认安全软件没有隔离安装目录中的 `reflex-runtime.exe`；
- 不要单独下载或替换 Runtime 文件；
- 仍然失败时导出诊断包，并附上诊断编号。

## 3. Provider 相关错误

| 错误类别 | 含义 | 建议处理 |
|---|---|---|
| 未配置 Provider | 未保存可用密钥或模型 | 在设置中选择 Provider、模型并重新保存密钥 |
| 认证失败 | API Key 无效、过期或无权限 | 在 Provider 后台核对密钥和模型权限，再重新录入 |
| 请求过多 | Provider 返回限流 | 稍后重试，避免连续重复提交 |
| 请求超时 | 网络或 Provider 响应过慢 | 检查网络后重试；不要在超时后连续点击生成 |
| 网络错误 | 无法建立安全连接 | 检查代理、防火墙、DNS 和系统时间 |
| 服务不可用 | Provider 暂时故障 | 稍后重试或手动切换已配置的 Provider |
| 响应无效 | 返回格式与当前协议不兼容 | 核对模型和接口地址；OpenAI-compatible 服务可能需要调整配置 |

Reflex 不会在错误后自动切换到另一个付费 Provider。

## 4. Reflex Cloud 相关错误

| 提示 | 建议处理 |
|---|---|
| 今日免费额度已用完 | 次日再试，或切换到自备 Provider |
| 当前网络请求过于频繁 | 等待一段时间后再试 |
| 云端当前繁忙 | 保留当前输入，稍后重新提交 |
| 产品改进授权不足 | 在“设置 > 安全与隐私”中检查产品改进计划 |
| 隐私授权版本已更新 | 刷新授权状态并重新确认后再提交 |
| 云端 Provider 尚未配置 | 切换自备 Provider，或等待服务管理员完成配置 |
| 今日云端服务预算已用完 | 稍后或次日再试，或切换自备 Provider |

免费额度、网络限流和服务总预算是独立门禁，任一门禁拒绝时不应重复扣减其他额度。

## 5. 快捷键或剪贴板不可用

- 全局快捷键可能与其他应用冲突，请在设置中更换组合键；
- 自动替换剪贴板会覆盖现有内容，首次使用仍需确认；
- 读取失败时可直接粘贴文本，不需要授予整机文件访问权限；
- 企业安全策略可能阻止全局快捷键或剪贴板访问。

## 6. 历史记录异常

- 不要直接编辑或删除历史数据库及其 `-wal`、`-shm` 文件；
- 升级前保留数据目录和迁移备份；
- 若应用提示历史损坏，先停止写入并保留现场，再使用应用提供的恢复流程；
- Provider 密钥不在历史数据库中，恢复历史后可能需要重新确认密钥状态。

## 7. 语义模型无法下载或加载

语义模型是可选能力。可以取消下载或关闭插件，基础场景识别和生成流程仍可使用。检查网络、磁盘空间和模型目录权限后再重试。

## 8. 反馈或诊断包发送失败

- 反馈失败不会删除当前结果，可稍后重新提交；
- 截图失败时可以不附加截图继续反馈；
- 诊断包无可导出记录时，先启用本地诊断并复现一次问题；
- 导出被安全扫描拒绝时，不要绕过检查或手工打包整个数据目录。

## 9. 删除云端数据

在“设置 > 安全与隐私”选择“删除云端数据”。该操作会删除当前安装身份关联的授权、反馈、附件、额度和改进样本，并使旧安装身份失效。操作不可撤销。

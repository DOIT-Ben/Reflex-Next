## 用户可见层

- 默认页与完成结果菜单均可打开模板管理。
- 空模板库可以新建；表单包含名称、分类、标签、说明和模板内容。
- `390x800` 窄屏下模板列表与编辑器可滚动，底部保存与应用操作可达。
- Esc 关闭模板管理并恢复入口焦点。

## 安全边界

- 模板数据只作为非敏感配置扩展保存；宿主会拒绝任意包含密钥类字段的扩展。
- 模板不进入 Provider 配置、SecretStore、Core 请求协议或插件私有配置。
- 变量缺失时不应用模板，避免将未渲染占位符写入主输入区。

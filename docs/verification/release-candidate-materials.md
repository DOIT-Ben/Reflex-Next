# alpha.8 发布候选物料验证

验证日期：2026-07-15
验证基线：`2682432`
版本：`0.7.0-alpha.8`
平台：Windows 11 x64

## 物料组成

`tools\new_release_candidate.ps1` 将以下内容组装为一个可复验目录：

- NSIS 安装包、`Reflex.exe` 和 `reflex-runtime.exe`；
- 11 份 CycloneDX 1.5 SBOM 及其锁文件哈希清单；
- `RELEASE_NOTES.md`、`RECOVERY.md`；
- `SHA256SUMS.txt` 和 `release-manifest.json`。

验证器会重新计算所有文件哈希，检查文件集合、签名状态、SBOM 组件、当前源码提交、
版本、标签状态、发布说明、恢复指南和锁文件来源，并再次执行敏感信息扫描。

## 实机结果

本机审查包共 19 个文件，包含 3 个可执行物和 11 个组件 SBOM。安装包 SHA-256：

```text
439adc75d284b7170d7a17e970238bc5fa504e6a9d96679297e5088f13456db4
```

生成器和验证器均返回成功；哈希、SBOM、来源绑定和敏感信息检查通过。清单中的状态为：

| 门禁 | 状态 | 原因 |
|---|---|---|
| 版本一致性 | 通过 | 当前产品版本统一为 alpha.8 |
| SBOM | 通过 | 11 个组件和锁文件哈希一致 |
| 构建物扫描 | 通过 | 3 个可执行物通过敏感信息扫描 |
| 签名 | 未通过 | 本机包尚未签名 |
| 发布标签 | 未通过 | 当前提交没有对应的 `v0.7.0-alpha.8` 标签 |
| 工作树清洁 | 未通过 | 工作区保留用户已有改动 |
| `release_ready` | 未通过 | 正式发布门禁必须全部通过 |

因此该目录是“可验证的内部审查物料”，不是可公开分发的正式安装包。验证器的
`-RequireReady` 会稳定返回 `release_not_ready`，防止误发。

2. 使用正式代码签名证书签署三个 Windows 可执行物。

4. 重新生成 SBOM 和发布候选目录，运行 `-RequireReady`。

# Reflex Next 首次成功受控试用

## 目的

验证中文知识工作者能否在无指导条件下，于 3 分钟内完成一次真实工作文本的输入、生成和采用。

## 参与者与材料

- 10 名日常处理邮件、报告、会议跟进或产品说明的中文知识工作者；
- 每位参与者自带一段可公开或已脱敏的真实工作文本；
- 提供已安装的测试版本和可用的 Cloud 免费试用或参与者自备 Provider；
- 不记录原文、结果、API Key 或完整错误信息。

## 主持方式

1. 只说明任务目标：请把这段文字处理成你愿意直接采用的版本；不讲解按钮和模型设置。
2. 记录从打开应用到首次出现结果的用时。
3. 观察参与者是否复制结果或替换剪贴板，以及是否使用对比原文、再调整。
4. 生成后询问两句：文本会发送到哪里？这次结果会不会保存？
5. 记录阻断、困惑点和原话摘要；按严重度归类，但不写入文本内容。

## 通过标准

- 至少 8/10 人在 3 分钟内得到首个结果；
- 至少 6/10 人主动复制结果或替换剪贴板；
- 参与者能够正确复述数据处理路径和历史保存状态；
- 没有 P0 或 P1 阻断；负反馈可归入明确的问题类别。

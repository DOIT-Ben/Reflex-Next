# Reflex Next 前端重设计整合记录

## 目标

将外部重设计稿的信息架构、主工作台布局和交互反馈迁入现有
`apps\tauri-host`，同时保持 Tauri Host、Rust Sidecar 和 Python Core 为唯一业务链路。

## 技术决策

- 保留 Svelte 5 + Vite，不迁入 Next.js 运行时；
- 保留现有 `CoreBridge`、`TauriHostApi`、`CapabilityBridge` 和设置、历史桥接；
- 不迁入 Next API Routes、Prisma、ZAI SDK、memory-store 或浏览器端 `/api` 请求；
- 仅增加 `@lucide/svelte`，并按图标文件直接导入，避免扫描整个图标目录；
- 旧调整面板和增强功能弹层继续复用现有真实动作，后续分视图打磨。

## 已整合

- 44 px 标题栏：Provider 状态、命令入口、缩放、尺寸和窗口控制；
- 48 px 左侧导航：工作台、模板、批处理、翻译、Markdown、插件、历史和设置；
- 输入与结果双栏工作台，紧凑视口自动堆叠；
- Empty、Running、Completed、Cancelled 和 Error 状态；
- 复制、替换剪贴板、重新生成、导出、翻译、预览、对比、评分和历史入口；
- `Ctrl+K` 命令面板、`Ctrl+Enter` 生成和原有分层 `Esc` 语义；
- 底部运行状态、字数、语言、主题和版本信息；
- 关闭按钮继续调用 `hide_main_window`，保持关闭到托盘。

## 验证证据

- 前端单元与架构契约：23 个文件、148 项通过；
- Vite 生产构建通过，无 Svelte 可访问性警告；
- 构建模块由总入口导入时的 3590 个降至按文件导入后的 184 个；
- 生产 JS 主包约 233.85 kB，gzip 约 72.53 kB；
- 浏览器映射在 680x480、760x540、920x720 均无页面滚动和控件裁切；
- Demo Core 完成输入、流式生成、完成态和结果动作闭环；
- 命令面板与设置导航实跑通过，控制台无应用错误；
- 导航悬浮态改变背景与文字颜色，并在验证后恢复正常状态。

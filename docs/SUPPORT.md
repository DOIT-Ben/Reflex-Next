# Reflex 支持范围

适用版本：`0.7.0-alpha.8`

## 1. 当前发布状态

当前版本属于 Alpha 预览版本，适合受控试用，不是正式稳定版。安装包尚未完成正式代码签名和自动更新，因此不应从不可信来源获取或公开推广。

## 2. 操作系统

| 环境 | 状态 |
|---|---|
| Windows 11 x64 | 已完成构建、安装、覆盖安装、卸载和重装验证 |
| Windows 10 x64 | 功能目标包含该平台，但尚无与 Windows 11 同等级的发布证据 |
| Windows ARM | 当前不支持 |
| macOS / Linux | 当前桌面宿主不支持 |

桌面界面依赖 Microsoft Edge WebView2 Runtime。Windows 11 通常已包含该组件；缺失时应先从 Microsoft 官方渠道安装。

## 3. Provider 与云服务

- MiniMax 是当前完成真实流式生成和取消验证的首个 Provider。
- OpenAI-compatible 插件具备协议和错误处理测试，但具体服务兼容性取决于对方接口，当前按实验性能力处理。
- Reflex Cloud 是可选服务。服务未部署、未配置或额度耗尽时，用户仍可切换到自备 Provider。
- 自备 Provider 的可用性、价格、内容政策和数据处理由对应服务商负责。
- 请求失败时不会返回模拟结果，也不会自动切换到另一个可能产生费用的 Provider。

## 4. 本地能力

Core、内置模板和基础场景识别不要求 GPU。语义模型属于可选插件，下载失败或未启用时会回退到轻量场景识别，不应阻塞基本优化。

历史、翻译、批处理、Markdown 预览和模板管理以插件或独立工作视图提供。第三方插件安装尚未开放为正式支持能力。

## 5. 当前不承诺的能力

- 正式代码签名和自动更新；
- Windows 10 发布级兼容保证；
- 历史官方安装包和所有真实用户数据的无损跨版本迁移；
- 所有 OpenAI-compatible 服务的完整兼容；
- 未经审核的第三方插件；
- 离线大模型推理和 GPU 加速保证。

## 6. 获取帮助

先按 [TROUBLESHOOTING.md](TROUBLESHOOTING.md) 排查。仍无法解决时，可通过应用内反馈入口提交问题，或导出脱敏诊断包。

有效的问题信息包括：

- Reflex 版本和 Windows 版本；
- 错误页面显示的错误类别和诊断编号；
- 是否使用 Reflex Cloud、自备 MiniMax 或 OpenAI-compatible Provider；
- 可重复的操作步骤和期望结果；
- 是否发生在安装、启动、生成、取消、历史或插件操作阶段。

请勿提交 API Key、完整输入、完整结果、Windows 凭据或未经检查的数据库文件。

# Reflex 0.7.0-alpha.8 发布说明

发布日期：2026-07-15

## 主要变化

- 桌面端从 Runtime 动态读取 Provider、模型和默认模型，设置页不再维护重复目录。
- 完善小浮窗、历史、结果对比、翻译、批处理、Markdown 预览和插件状态入口。
- Provider 请求支持流式输出、取消、超时、有限重试和稳定错误分类。
- 历史记录使用本地加密 SQLite 存储，配置和历史迁移保留恢复路径。
- 增加反馈、可选截图、改进计划授权、免费额度查询和数据删除入口；这些能力仅在
  Reflex Cloud 已部署并配置时启用。
- 增加脱敏诊断和诊断包导出，错误页面提供可复制的诊断编号。

## 安全与隐私

- Provider 密钥保存在 Windows 凭据管理器中，不写入配置、日志、历史导出或安装包。
- 本地诊断默认关闭，不自动上传；导出前再次执行敏感信息过滤。
- 提示词、结果和反馈截图是否上传由对应授权控制，客户端自备 Provider 密钥不会发送到云端。
- Release Host 不启用开发 Mock Provider。

## 当前验证

- Windows 11 完成构建、安装、Sidecar 启动、覆盖安装、卸载和重装验证。
- 历史插件全套 159 项通过；旧 Runtime 生成的加密历史可由当前 Runtime 读取和续写，
  并保留迁移前备份。
- 新取消夹具完成 2,000 次请求/取消复验，未观察到迟到分片、请求串线或残留 Runtime。

## 已知限制

- 当前本地安装包尚未完成正式代码签名，不适合公开推广或替代来源验证。
- Windows 10 尚无与 Windows 11 同等级的干净构建和生命周期证据。
- 历史官方安装包与真实用户数据的完整升级、回滚仍需单独验证。
- 72 小时长期运行门禁正在重新准备，当前版本不能据此宣称达到正式稳定版标准。
- 自动更新和签名回滚包尚未提供。

这是 Alpha 预览版本，不是面向普通用户公开推广的正式版本。
